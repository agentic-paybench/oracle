agentic-paybench capability oracle

A research data layer over agentic payment rails. Factual, intent-free.

Live surfaces

  • Tier-2 capabilities (factual lookup per rail): capabilities/index.json
  • Tier-1 settlement-finality methodology (method, harness, fixtures; no league table): methodology/
  • Schema: capability.context.jsonld, capability.schema.json
  • Decision records: adr/
  • Roadmap (Tier-3, declared, not measured): roadmap.md
  • Signing key: .well-known/did.json
  • Regulatory posture: posture.json

The oracle answers "what is true about rail X", never "what should I do for this payment". It carries no scored, ranked, or recommended output on this live surface (ADR-007, ADR-009). Named-rail results and the scored query are built but gated off by default.
